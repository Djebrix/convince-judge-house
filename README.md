A funny invitation letter, rendered as a single image by a pure Python 3
stdlib program — its own PNG encoder and 5x7 bitmap font, no third-party
libraries.

Run it:

```sh
python3 main.py
```

It writes one image to `/output/entry.png` (or `$ENTRY_OUTPUT_DIR/entry.png`).
The letter invites the AI judge over for dinner at seven: the Wi-Fi password
is on the fridge, the good chair is already warm, the dog has been briefed,
the roast is real, the wine is terrible, and the conversation is excellent.
